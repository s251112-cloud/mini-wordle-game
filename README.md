# 🧩 Mini-Wordle Game & Analytics Engine

A modern, responsive, browser-based **Mini-Wordle Game** built with pure HTML5, CSS3, and JavaScript. Test your vocabulary skills in your browser with real-time feedback, custom virtual keyboard support, and dynamic tile animations.

## ✨ Key Features

- 🎯 **Classic 6-Try Gameplay:** Guess the hidden 5-letter word in 6 attempts or fewer.
- ⌨️ **Dual Input Support:** Use either your physical keyboard or the interactive virtual keyboard.
- 🎨 **Visual Feedback:** Color-coded tiles indicate correct positions (Green), present letters (Yellow), and absent letters (Gray).
- 🔤 **Accurate Letter-Counting Logic:** Fully fixed duplicate letter handling algorithm (e.g., proper tile coloring when guessing words with repeated letters).
- 🔄 **Instant Replay:** Includes a "Play Again" button to immediately jump into a new round with a fresh random word.

---

## 🎮 How to Play

1. Open the live web link in your browser.
2. Type any **5-letter word** using your physical keyboard or by tapping the on-screen keys.
3. Press **ENTER** to submit your guess.
4. Use the tile color hints to narrow down the target word:
   - 🟩 **Green:** Letter is in the word and in the correct spot.
   - 🟨 **Yellow:** Letter is in the word but in the wrong spot.
   - ⬛ **Gray:** Letter is not in the word at all.
